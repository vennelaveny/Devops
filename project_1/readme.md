# WonderFest - Event Registration Form

A simple, responsive event registration page built with HTML, CSS, and JavaScript.

## Features
- Personal, academic, and event participation details form
- Client-side validation for required fields (Name, Email, College)
- Responsive layout (mobile-friendly)
- Success message on submission

## How to Run
1. Download `index_simple.html`.
2. Double-click the file — it will open directly in your browser.

**OR** run it with Live Server (VS Code):
1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index_simple.html` → **Open with Live Server**.

## Tech Used
- HTML5
- CSS3
- JavaScript (Vanilla)
